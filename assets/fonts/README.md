# Embedded fonts

Ledgerline includes Noto Sans Arabic Regular and Bold to render English and Persian invoice and receipt PDFs offline.

The font files are from the Noto Sans Arabic family maintained by the Noto Project:
https://github.com/notofonts/notofonts.github.io/tree/main/fonts/NotoSansArabic/hinted/ttf

They are distributed under the SIL Open Font License 1.1. The full license text is in `OFL.txt`.
